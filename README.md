# Projeto Saúde

Este repositório contém o projeto "Projeto Saúde", desenvolvido como um exercício prático da trilha de desenvolvimento Front-End da fase 1 da Residência em Software RESTIC36. O objetivo é consolidar os conhecimentos adquiridos, aplicando técnicas de HTML, CSS e JavaScript para criar uma página informativa e interativa sobre saúde e bem-estar.

## Descrição do Projeto
O "Projeto Saúde" é uma página web que aborda três pilares fundamentais para a qualidade de vida:

1. **Alimentação Saudável:**
   - Dicas para manter uma dieta equilibrada.
   - Sugestões de refeições saudáveis para diferentes momentos do dia.

2. **Exercícios Físicos:**
   - Sugestões de atividades físicas para níveis iniciantes, intermediários e avançados.
   - Importância da prática regular de atividades físicas.

3. **Saúde Mental:**
   - Estratégias para promover o bem-estar emocional.
   - Dicas para lidar com o estresse e manter o equilíbrio mental.

4. **Calculadora de IMC:**
   - Uma ferramenta interativa para calcular o Índice de Massa Corporal (IMC) com base no peso e na altura informados pelo usuário.

## Tecnologias Utilizadas

- **HTML5:** Estruturação do conteúdo da página.
- **CSS3:** Estilização e design responsivo.
- **Bootstrap 5:** Auxílio no layout responsivo e componentes prontos.
- **JavaScript:** Lógica interativa, incluindo o cálculo do IMC.

## Estrutura do Projeto

O projeto é organizado da seguinte forma:

```
projeto-saude/
|-- index.html         # Arquivo principal da página
|-- index.css          # Estilização personalizada
|-- script.js          # Função de cálculo do IMC
|-- img/               # Imagens utilizadas no projeto
|   |-- banner site.png
|   |-- banner comida saudável.png
|   |-- banner exercício.png
|   |-- banner saude-mental.png
```

## Funcionalidades

- Navegação interativa por meio de links ancorados.
- Seções informativas sobre temas relacionados à saúde.
- Design responsivo para diferentes tamanhos de tela.
- Calculadora de IMC que exibe o resultado diretamente na página.

## Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/nadsonsousa95/projeto-saude.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd projeto-saude
   ```

3. Abra o arquivo `index.html` em seu navegador preferido.
